## Comparison: MBE70 vs MBE7000

| Variable | MBE70 | MBE7000 | Different? |
|----------|-------|---------|------------|
| ethaddr | 80:69:1A:B2:C1:08 | 00:03:7f:ba:db:ad | YES (per-device) |
| Everything else | — | — | NO (identical) |

**Conclusion:** The U-Boot env is shared/same across both MBE70 and MBE7000.
The `bootipq` command and all env vars are identical. The only per-device
value is `ethaddr` (MAC address).

## Critical Implication for Recovery

The stock env is already 100% correct. To recover the bricked MBE7000,
we only need to restore `bootcmd=bootipq`. Nothing else needs changing.

For OpenWrt boot on MBE7000 (which has phdr-based `bootipq`):
```
fw_setenv bootcmd 'run bootpart1'
```

For OpenWrt boot on MBE70 (which has direct `bootipq`):
```
fw_setenv bootcmd 'run bootpart1'
```

Both devices: `bootcmd='run bootpart1'` works. The `bootpart1` env var
contains the same direct `mmc read` + `bootm` command on both.
